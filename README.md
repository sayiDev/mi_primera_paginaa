# Mi Primera Página

Este repositorio contiene mis primeros pasos con HTML, CSS y JavaScript.

## Propósito

Practicar los conceptos básicos de desarrollo web creando una página sencilla.

## Uso

Para utilizar el proyecto, abre el archivo index.html en el navegador. Allí podrás visualizar la página y hacer clic en el botón "Mostrar mensaje". Para ver el mensaje generado con JavaScript, abre la consola del navegador.
